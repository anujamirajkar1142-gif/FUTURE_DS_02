# Customer Retention & Churn Analysis Dashboard

## Internship Task

Future Interns – Data Science & Analytics Internship

Task 2: Customer Retention & Churn Analysis

## Project Overview

This project analyzes customer churn patterns and retention drivers using the Telco Customer Churn dataset. The dashboard identifies factors influencing customer churn and provides actionable recommendations to improve customer retention.

## Tools Used

- Power BI
- DAX
- Data Cleaning & Transformation

## Key KPIs

- Total Customers: 7,043
- Churned Customers: 1,869
- Churn Rate: 26.54%
- Average Tenure: 32.37 Months
- Total Revenue: $16.06M

## Dashboard Features

- Churn Rate Analysis
- Contract Type Analysis
- Payment Method Analysis
- Internet Service Analysis
- Customer Lifetime Trend
- Churn Risk Heatmap
- Churn Drivers Treemap
- Retention Summary Table

## Key Insights

- Month-to-month customers have the highest churn risk.
- Fiber Optic users churn more than DSL users.
- Electronic Check customers show the highest churn rate.
- Longer-tenure customers are more likely to stay.

## Recommendations

- Encourage annual and two-year contracts.
- Promote automatic payment methods.
- Improve onboarding during the first few months.
- Focus retention campaigns on high-risk customers.
